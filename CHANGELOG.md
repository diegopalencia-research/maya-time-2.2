# Changelog

## 0.2.1 — 2026-11-21

- Expanded the Overview sky panel into a Sky Observatory.
- Added a geocentric tropical zodiac wheel with planetary markers and major-aspect lines.
- Added longitude-based aspect detection with a 6° orb and short, clearly labeled traditional symbolic descriptions.
- Added heliocentric planetary XYZ positions in the J2000 mean ecliptic frame and an AU-scaled XY projection.
- Added full-system and inner-system views with dotted mean orbital-radius guides.
- Added a 30-day modeled lunar illumination curve with calculated principal-quarter markers.
- Expanded astronomy methodology, coordinate-frame notes and technical documentation.


## 0.2.0 — 2026-11-01

- Added a live Guatemala / UTC (ISS operations / Zulu) mission clock.
- Added independent selected-date navigation with previous, next, date picker and Today controls.
- Replaced single tasks with recurring activity series and dated occurrences.
- Added once, daily, selected-weekday and monthly recurrence rules.
- Added local SQLite CRUD and migration from the v0.1.0 task table.
- Added Supabase Auth and PostgreSQL storage with owner-only Row Level Security policies.
- Added Excel workbook and CSV exports.
- Expanded time-use analysis and database documentation.
- Added tests for recurrence, storage migration, exports and SQL time formats.
- Preserved the existing monochrome mission-instrument visual direction.
